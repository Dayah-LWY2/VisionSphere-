# VisionSphere
A forum web application developed for authorized users of Vision University College. It was assigned as a Final Year Project (FYP) to be completed prior to the internship. The system was developed using the Agile methodology. The frontend is built with HTML, CSS, JavaScript, and EJS, while the backend uses Node.js, Express.js, RESTful API architecture, and MongoDB Atlas for data management.

The prototype and all multimedia content were created by my partner, Azlina Lee.

Access to the system is restricted to authorized users only. Interested users must contact the project owner via Gmail or WhatsApp to obtain access and further information. The link can be accessed below:
